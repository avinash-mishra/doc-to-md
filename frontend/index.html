How the score works. An arbitrary PDF has no ground-truth markdown, so the composite is a weighted blend of four observable signals, all relative to the same document: coverage 30% (text recovered vs. the best engine on this file), structure 25% (headings, tables, lists, links that survived), cleanliness 25% (absence of cid artifacts, control/replacement characters, whitespace noise) and integrity 20% (tokens that read as real words, no char-spacing damage, broken hyphenation or glued words). Treat it as a ranking aid, then read the markdown — the eye is still the judge.
